# Учёт расходов

Десктоп-приложение на Tkinter для учёта личных расходов: ввод трат, просмотр по месяцам, кольцевая диаграмма по категориям и экспорт в CSV. Не требует установки библиотек, только стандартный Python.

## Возможности

- Добавление расхода: сумма (можно с запятой), категория, дата в формате ДД.ММ.ГГГГ, комментарий; `Enter` добавляет запись
- Проверка ввода: сумма больше нуля и корректная дата, иначе понятное предупреждение
- 9 категорий: еда, транспорт, жильё, связь и интернет, развлечения, одежда, здоровье, учёба, другое
- Просмотр по месяцам с переключением ◀ ▶ и фильтром таблицы по категории
- Итог за месяц и средний расход в день
- Кольцевая диаграмма по категориям с процентами и легендой, нарисованная на `Canvas` без matplotlib
- Удаление выделенных строк, в том числе нескольких сразу, кнопкой или клавишей `Delete` с подтверждением
- Экспорт месяца в CSV, который корректно открывается в Excel
- Данные хранятся в SQLite-файле `expenses.db` в папке, из которой запущено приложение

## Стек

Python 3.10+, Tkinter/ttk, SQLite (`sqlite3`), pytest для тестов.

## Как запустить

```bash
python app.py
```

Нужен Python 3.10+ с Tkinter: на Windows и macOS он ставится вместе с Python, в Linux: `sudo apt install python3-tk`.

Тесты хранилища:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install pytest
python -m pytest -v
```

Тесты запускаются в GitHub Actions (`.github/workflows/tests.yml`) на Python 3.11 и 3.12.

Сборка в один исполняемый файл:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed app.py
```

## Настройка

Список категорий задаётся в `CATEGORIES` в `storage.py`, цвета диаграммы в `PALETTE` в `app.py`.

## Структура проекта

```
app.py           # интерфейс: форма, таблица, переключение месяцев, диаграмма, экспорт
storage.py       # слой данных на SQLite: добавление, удаление, выборки, экспорт CSV
test_storage.py  # тесты хранилища на временной базе
```

## Как это устроено

- Слой данных (`Storage`) ничего не знает об интерфейсе и покрыт тестами; интерфейс только вызывает его методы.
- В таблице стоит ограничение `CHECK (amount > 0)` и индекс по дате; выборка за месяц идёт по префиксу `ГГГГ-ММ`.
- Суммы по категориям считаются в SQL (`GROUP BY` с сортировкой по убыванию).
- Диаграмма рисуется секторами `create_arc` с белым кругом в центре; для единственной категории (360°) рисуется овал, потому что Tk не умеет сектор ровно в 360°.
- CSV пишется в `utf-8-sig` с разделителем `;`, даты в формате ДД.ММ.ГГГГ и запятой в дробной части, чтобы русский Excel открыл файл без настройки.
- Средний расход в день для текущего месяца считается по прошедшим дням, для остальных по 30 дням.
